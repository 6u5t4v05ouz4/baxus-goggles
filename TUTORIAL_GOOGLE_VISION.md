# How to Get a Google Vision API Key

This tutorial teaches you how to create a project on Google Cloud and obtain an API key to use the Google Vision API.

## Step 1: Access Google Cloud Console

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Sign in with your Google account.

## Step 2: Create a New Project

1. At the top of the page, click the project selection menu.
2. Click **New Project**.
3. Give your project a name and click **Create**.

## Step 3: Enable the Vision API

1. With your project selected, in the left menu, go to **APIs & Services > Library**.
2. Search for **Cloud Vision API**.
3. Click on **Cloud Vision API** and then click **Enable**.

## Step 4: Create Credentials (API Key)

1. In the left menu, click **APIs & Services > Credentials**.
2. Click **+ Create Credentials** and select **API Key**.
3. An API key will be generated. Copy it and keep it safe.

> **Security Tip:** Restrict your API key usage by clicking **Restrict Key** to set usage limits and protect your project.

## Done!

Now you can use your API key to access the Google Vision API in your projects.
